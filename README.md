## 工作边界

- 目标是 **两个自然周 / 最多十个工作日** 内完成五端可操作展厅原型，闺蜜机为重点；不是承诺五套量产系统。
- 公开展示站属于独立的 [base-prototype](https://github.com/sanchuang-dev/base-prototype) 多项目展厅；**业务源文件和产品规格留在本仓库**，不得复制业务代码污染该仓库 main。
- 产品规格以本仓库 docs 为准；会议导出的 Word/PDF 仅为阅读快照，迭代须回写本仓库。
- 不为养老院开发床位、护理、排班、收费等内部业务基建；外部场所和商家向平台提供内容及服务。
- 演示能力、技术 PoC 和实际可用功能须明确区分，严禁用预录内容假冒实时 AI。
